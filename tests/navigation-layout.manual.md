# 底部固定菜单遮挡回归

2026-09-27，微信开发者工具，iPhone 12/13 (Pro) 模拟器。

问题：固定菜单使用半透明白色，商品价格、图片和加购按钮会透入菜单；首页底部的固定间距没有包含底部安全区。

修复：菜单与操作栏使用不透明白色；带菜单的普通页面和分类右侧列表预留 `110px + safe-area-inset-bottom`。保留图片、字体、卡片与菜单尺寸；不覆盖购物车原有双层操作栏预留间距。

- 分类右侧列表滑到底：最后一个商品名称、规格、价格、加购按钮及“没有更多商品了”完整显示。
- 分类顶部与左侧菜单保持固定，仅右侧商品列表滚动。
- 底部菜单可正常切换首页和分类。
- 现有 8 项单元测试通过；微信小程序及 H5 构建通过。

长页面仍需正常上下滚动，不通过缩小图片或字体强行把所有商品放在一屏。

## 菜单栏本身的裁切复查

用户圈出的是菜单栏，不是商品列表。上一轮将两者混淆，不能以商品滑到底的截图作为菜单栏验收证据。

购物车角标定位在按钮上方 `3px`，按钮默认 `overflow: hidden` 会裁掉角标上沿。仅为 `.tabbar button` 设置 `overflow: visible`，不调整菜单高度、位置、图标或文字，也不改变购物车数据。
