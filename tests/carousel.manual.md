# 首页轮播回归记录

日期：2026-09-27；环境：微信开发者工具，iPhone 12/13 (Pro) 模拟器，本地 Java 8088。

## 原因与修复

首页原来是静态图片，只读取 `decoration.banners` 第一条，并固定显示三个圆点。
现使用原生 `swiper`，读取所有启用的后台轮播，按 `sort` 排序；多图每 4 秒自动循环，支持左右滑动。
圆点和当前图片同步；点击图片或按钮使用各自配置的 `target`；页面隐藏暂停自动播放，返回恢复。
沿用原有图片、渐变、字号、按钮和轮播尺寸，不新增固定业务图片或文案。

## 配置说明

当前商城 2 的原配置仅有一条启用轮播（`tea`）。单图不自动切换，不展示虚构的三个圆点。
后台“营销与配置 → 店铺装修 → 首页轮播配置 JSON”配置至少两条启用且有图片的轮播，才会自动播放。
图片、文案、按钮文字、目标页面、排序、启用状态继续全部从后台读取。
